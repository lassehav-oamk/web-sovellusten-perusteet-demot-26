# W3L3 – Event listener -starterit

Viisi toisistaan riippumatonta harjoitusta. Jokainen kansio on uusi lähtöpiste, jotta aiemman harjoituksen virheet eivät estä tunnilla etenemistä.

1. `01-click` – ensimmäinen click-event listener
2. `02-counter` – tapahtuma ja JavaScriptissä säilytettävä tila
3. `03-product-button` – createElement + event listener
4. `04-products` – useita tuotteita ja jokaiselle oma tapahtumankäsittely
5. `05-filter` – tuotteiden suodatus hakukentän tekstin perusteella

Avaa harjoituksen `index.html` selaimessa ja `app.js` VS Codessa.

Harjoituksissa 01–04 ei ole tarkoituksella valmiita event listener -ratkaisuja. Ne kirjoitetaan tunnilla vaiheittain. Harjoituksessa 05 render-funktio ja input-tapahtumankäsittelijä ovat valmiina; opiskelijan tehtävä on toteuttaa tuotteiden suodatus.
